# DealCard PK

Static web app that shows bank credit/debit card discounts in Pakistan — daily, weekly and monthly — with city and category filters. Add your own cards to see only the deals you can use.

**The deals in `data.js` are sample data, not live offers.** Replace `RAW_DEALS` with real, verified offers before relying on it.

No build step: open `index.html`, or deploy the folder as a static site. Cards are stored in the browser's localStorage only.
